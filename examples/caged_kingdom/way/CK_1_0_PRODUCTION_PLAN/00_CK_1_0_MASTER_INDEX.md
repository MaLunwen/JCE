# Caged Kingdom 1.0 — 首发生产规划总索引

> **目标发布日期**：2027-01-29  
> **正式开发窗口**：2026-09-01 至 2027-01-29  
> **长期设定权威**：`CK_SETTING_BIBLE_v1.1.md`  
> **长期资产权威**：`CK_Asset_Manifest_v1.0.md`  
> **本套文档职责**：定义五个月开发窗口内实际交付的 Caged Kingdom 1.0，不覆盖长期五幕、七女魔王和三大区蓝图。

## 1. 首发版本一句话定义

> **一款以拉斯帕兹解放战为完整故事的单人第三人称紧凑开放世界动作冒险：玩家在王都废墟和拉斯帕兹接任务、驾驶符文载具、战斗、逃避 Wanted、经营装备与安全屋，最终击败薇雯和米拉，并决定城市归属。**

## 4. 权威关系

```text
SETTING_BIBLE（长期世界观/角色/地区/七魔王）
             ↓
Asset Manifest（长期全量生产资产）
             ↓
CK 1.0 Production Plan（2027-01 首发裁剪）
             ↓
场景、Prefab、任务数据、游戏代码、测试
```

发生冲突时：

1. 世界观、角色身份和专有名词以 Setting Bible 为准；
2. 首发是否制作、制作到什么深度，以本套文档为准；
3. 代码和资产不得自行扩展首发范围；
4. 新内容必须先更新对应规划，再进入生产。

## 5. 三层优先级

### R0 — Release Blocking

缺少即不能发布：

- 玩家移动、相机、战斗、载具；
- A+B 首发地图；
- 12 主线；
- 两个 Boss；
- 存读档；
- Wanted；
- 经济和必要商店；
- 全流程 UI；
- 键鼠与手柄；
- 崩溃、任务阻塞和存档损坏为零。

### R1 — Release Quality

首发应完成，但可以在最后阶段降低表现复杂度：

- 8 支线；
- 4 类活动；
- 3 电台；
- 行人和基础交通；
- 两个结局；
- 完整 VFX/SFX；
- 动态委托；
- Toon 美术统一。

### R2 — Post-launch Candidate

不足时可延期：

- 高级人群行为；
- 大量环境破坏；
- 次要过场动画；
- 第二套死亡动画；
- 大量室内装饰；
- 额外电台内容；
- 米拉异形真身；
- 更多武器皮肤。

## 6. 首发完成定义

只有同时达到以下条件，才能称为 CK 1.0 完成：

- 新存档可从开场连续完成 12 个主线并触发两个结局；
- 所有主线可重复从检查点恢复；
- 无任务软锁；
- 所有首发区域可稳定流式加载；
- 玩家、敌人、载具、Wanted、经济和存档形成完整循环；
- 最低配置达到目标性能；
- 外部测试者可独立完成游戏；
- 商店 Build 与发布 Build 一致；
- 所有资产有版权来源记录；
- 所有 R0 项通过独立回归测试。

## 7. 核心纪律

- 在切片一完成前，不制作 B 区大规模美术。
- 在切片二完成前，不制作第二个 Boss 的最终美术。
- 2026-11-30 后不得增加主要系统。
- 2026-12-15 后不得增加主线内容。
- 2027-01-08 后只修 P0/P1 缺陷。
- 任何新增功能必须删除或替换等量工作，不允许只增加范围。
