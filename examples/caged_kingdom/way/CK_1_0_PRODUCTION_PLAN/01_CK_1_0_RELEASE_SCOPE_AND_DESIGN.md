# Caged Kingdom 1.0 — 首发范围与游戏设计

## 1. 产品定位

- 单人第三人称动作冒险；
- 紧凑型开放世界；
- 任务驱动；
- 街机式载具；
- 轻度经济、改装和安全屋；
- 动漫 Toon Shading；
- 中世纪晚期 + 符文工业。

### 体验骨架

- GTA Vice City 式城市任务、联系人、Wanted、载具、电台和街头崛起；
- 动漫动作游戏式清晰轮廓、强反馈和易读 Boss 攻击；
- 西方奇幻中的龙、魔王、符文、废墟和魔法工业。

### 调性

黑色幽默、街头智慧、实用主义。主角不是天选英雄，不以宏大史诗独白作为主要叙事方式。

## 2. 故事范围

长期世界观仍包含七女魔王、五幕和三大区域。首发版本只完整讲述：

> Kael 从王都遗址难民营醒来，为求生成为引路人；进入拉斯帕兹后被黑市和抵抗军同时利用，逐步取得财富、装备与影响力，击败西区的薇雯和剧院区的米拉，最终选择让拉斯帕兹归属王室抵抗军，或成为独立城邦。

### 主要角色

| 角色 | 首发作用 |
|---|---|
| Kael / BagMan | 玩家角色 |
| Sera | 抵抗军代表、主线与王室结局 |
| Haro | 武器与载具改装 |
| Rat | 黑市任务和灰色路线 |
| Lily | 电台、信息和城市氛围 |
| 薇雯 | 西区 Boss |
| 米拉 | 剧院区 Boss |

Vel、其他女魔王和 C 区只通过对话、海报、电台新闻和远景建立存在感，不进入首发完整玩法。

## 3. 核心玩法循环

```text
探索
→ 接任务
→ 选择装备与载具
→ 驾驶/步行前往目标
→ 战斗、运送、追逐、潜入或逃脱
→ 产生 Wanted 与城市反应
→ 完成目标并撤离
→ 获得晶币、王玺金和声望
→ 购买武器、改装载具、安全屋升级
→ 解锁更高风险任务
→ 攻打区域 Boss
```

系统价值判断：

- 不能进入循环的系统，不做首发功能；
- 不能改变玩家决策或反馈的装饰性系统，优先降级；
- 每个主线至少使用两项核心系统；
- 每项核心系统至少被三个任务复用。

## 4. 玩家体验支柱

### 4.1 城市自由

玩家可在主线外步行或驾驶、访问商店和联系人、参与竞技场/竞速/送货/通缉追捕、获取晶币、触发并摆脱 Wanted、发现收集物、返回安全屋保存和整备。

### 4.2 战斗易读

- 轻攻击三连；
- 重攻击；
- 闪避；
- 格挡；
- 目标锁定；
- 近战与远程切换；
- 明确命中、受击和处决反馈；
- Boss 攻击用形状、颜色和音效提前预警。

### 4.3 载具爽快

- 快速进入/退出；
- 街机式转向；
- 碰撞可控；
- 路线明确；
- 用于追逐、送货和逃亡；
- 不做写实驾驶模拟。

### 4.4 城市会反应

- 犯罪触发 Wanted；
- 守卫按等级升级；
- 高 Wanted 时部分商店暂停；
- 电台新闻反映主线；
- 击败 Boss 后区域敌人、灯光、路障和 NPC 对话改变。

### 4.5 成长可见

成长来自新武器、武器升级、载具改装、安全屋功能、声望解锁和 Boss 奖励，不依赖传统角色等级。

## 5. 首发地图

### A 区：晨光之城王都遗址

承担开场教学、难民营、抵抗军基地、第一安全屋、低级商店、初次 Wanted、魔法马车教学和通往 B 区的道路。视觉为固定黄昏、暖灰废墟、夕照尘雾和难民营火光。

### B 区：拉斯帕兹

#### 中央集市

- 城市出生和任务集散；
- Rat 黑市；
- Lily 电台；
- Haro 改装铺；
- 竞技场入口；
- 公共商店；
- 行人和基础交通。

#### 西部工业区

- 熔炉、管道、仓库；
- 焰魔巡逻；
- 走私和抢劫；
- 薇雯 Boss。

#### 剧院与住宅区

- 剧院外立面和后台；
- 幻影敌人；
- 安全屋；
- 夜间任务；
- 米拉 Boss；
- 结局入口。

空港、码头完整玩法、冰川、魔森林深区、沼泽和 C 区只作远景、封锁门或后续版本入口。

## 7. 难度和失败

首发提供 Story、Normal、Hard。难度只调整玩家受到伤害、敌人攻击性、回复资源、Wanted 衰减和 Boss 容错，不改变主线内容。

玩家死亡回到最近检查点，保留已完成阶段，失去少量未存入安全屋的晶币，不丢关键物品。任务可因目标死亡、货物摧毁、离区、超时或关键载具不可恢复而失败，失败后可重试检查点或退出任务。

## 8. AI 调度技术的首发用途

功能名：**街头传闻 / Rumor Contracts**。

AI 或 T3 只能在固定 Schema 中选择：

- 任务模板；
- 区域；
- 目标类型；
- 敌人组合；
- 时间；
- 天气修饰；
- 风险级别；
- 奖励倍率；
- 货物；
- 可选叙述短句。

禁止生成任意代码、修改主线、新建未知组件、直接控制实体指针、修改经济全局规则或生成无界实体数量。

动态委托必须断网可用、可保存、可回放、同一 Record 可重建同一任务，且不成为主线完成条件。

## 9. 首发明确不做

- 多人联机；
- 七女魔王全线；
- C 区；
- 飞龙和飞艇；
- 水上驾驶；
- 四足坐骑；
- 角色切换；
- 队伍；
- 元素反应；
- 装备词条；
- 天赋树；
- 抽卡和内购；
- 房屋自由建造；
- 全语音；
- 复杂群体模拟；
- 写实车辆物理；
- 动态生成主线剧情；
- 让 LLM 直接生成脚本。

## 10. 范围变更规则

任何新增项必须记录玩家价值、所需系统、新资产数量、测试成本、替换掉的现有工作及是否影响发布日期。没有明确删除等量工作时，不批准新增。
