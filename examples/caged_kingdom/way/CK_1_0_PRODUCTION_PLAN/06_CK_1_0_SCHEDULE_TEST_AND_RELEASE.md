## 8. 缺陷等级

### P0

崩溃、存档损坏、主线无法继续、无法启动、无法完成结局、严重数据丢失或安全问题。

### P1

任务需重启才能继续、Boss 不可击败、载具卡死主线、严重性能问题、任一输入设备无法完成、大面积贴图/碰撞丢失。

### P2

明显表现错误、次要支线异常、音频问题、UI 布局和平衡。

### P3

小型穿模、文本、非阻塞视觉和可接受动画问题。

发布条件：

- P0 = 0；
- P1 = 0；
- P2 有明确清单和接受理由；
- P3 可进入补丁。
