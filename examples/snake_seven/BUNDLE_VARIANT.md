# Delivered portable Snake Bundle

`snake.jbundle` is one normal package implementing the seven component-policy
roles with Lua. It needs no external Python/Java/C# VM or native script DLL.

Observed controls: editor role execution, keyboard movement and wall collision;
the normal embedded public-SDK host also rendered and processed recorded input
from an unrelated single-EXE directory. Original seven-language authoring sources
and dedicated regression tools remain in `../../tests/consumers/snake_seven/`.

These observations do not certify all game outcomes or external seven-language
VM embedding. Stored best scores require an available host statistics service.
See BUNDLE_PROVENANCE.json and SOURCE_AND_TERMS.md for exact bytes and terms.
No muted QA package is delivered here.
