# Delivered normal Elemental Serenity Bundle

`elemental_serenity.jbundle` is the normal audio/content single-file portable Lua
scene package. The public SDK host loaded its dependency closure and rendered
after only the embedded executable was copied to an unrelated directory.

The portable scene preserves the selected director/firefly/flower/surface/fire
policies. It does not claim complete native application-bootstrap/AI orchestration,
external language VM parity, or audio correctness on every device. Font bytes and
private AI workflow inputs are not selected; the host supplies its default font.

First-party authoring inputs/tools remain in `../../tests/consumers/elemental_serenity/`;
original local assets and unknown/private content remain ignored. ASSET_PROVENANCE.json,
UPSTREAM_NOTICE.md and SOURCE_AND_TERMS.md retain upstream attribution and limitations.
BUNDLE_PROVENANCE.json identifies the normal bytes; no muted QA package is delivered.
