# Delivered normal Elemental Serenity Bundle

`elemental_serenity.jbundle` is the normal audio/content single-file portable Lua
scene package for the Windows target. It contains the maintained scene, six Lua
scripts and canonical project RenderPipeline settings. The authored primary
camera enables the sky; FXAA is enabled and TAA is disabled as requested. This
content correction is not a same-quality performance improvement.

The exact delivered bytes passed all63 Archive entry checks and Windows Editor
Bundle-open plus two Play/Stop cycles with a blue sky. A separate public SDK
consumer was exercised on Windows D3D12/Intel for day/night, seasons, rain and
camera movement. Its interactive session reached its safety budget; normal
Alt+F4 exit and CPU cleanup were verified in a separate session. These are scoped
functional observations, not all-feature, pixel-parity, GPU-completion, performance,
physical low-end or all-platform certification.

Font bytes and external native language VM payloads are not selected; the host
supplies its default font. First-party authoring inputs and the maintained pack
recipe remain in `../../tests/consumers/elemental_serenity/`. ASSET_PROVENANCE.json,
UPSTREAM_NOTICE.md and SOURCE_AND_TERMS.md retain attribution and limitations.
BUNDLE_PROVENANCE.json identifies these normal bytes; no muted QA package is delivered.
