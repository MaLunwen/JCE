# Minesweeper single-file Bundle

Open `minesweeper.jbundle` in the JCE editor. This is the normal audio/content
variant, not a muted QA package. The Bundle is one file; it requires no loose
scene, script or asset sidecars. It uses the portable Lua scene variant and
does not claim external seven-language VM embedding or native application parity.

Authoring source and dedicated regression tools: [`tests/consumers/minesweeper`](../../tests/consumers/minesweeper).
