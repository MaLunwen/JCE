# Dogfooding user-project source trees, one repo-relative directory per line.
#
# THIS FILE IS INTENTIONALLY EMPTY (owner decision, 2026-08-27).
#
# The general engine and editor are the product; a user project is a downstream
# dogfooding consumer.  A symbol that only a game names is NOT evidence that the
# editor consumes the engine, which is the question this gate exists to answer.
# So by default nothing here is scanned and such a symbol lands in NOWHERE --
# true with respect to the general surface, which is the surface that matters.
#
# The mechanism is kept rather than deleted because the distinction is real and
# was once worth 8x: of api_ui.h's 67 editor-unconsumed symbols, 45 were named
# by caged_kingdom.  Adding a line here brings that tree back as its own report
# column WITHOUT touching this gate's code.  It does not move the ratchet either
# way: the ratchet trips on `unconsumed` per umbrella, and every bucket below it
# is a breakdown of that same total.
#
# DO NOT EDIT THIS FILE TO ANSWER A LOCAL QUESTION.  It is tracked, and eleven
# worktrees on this machine share one .git, so a line added here to check
# something is a line that can be committed by somebody else's next commit.
# Ask the same question ephemerally instead -- same argument shape, nothing
# persisted:
#
#     python tools/lint/check_editor_consumption.py #         --user-projects examples/caged_kingdom --report
#
# Measured 2026-08-31 with that flag, on the main user project:
#
#     NOWHERE            405 -> 340      (65 of them are called by ck)
#     user-project         0 -> 138      (the other 73 come out of the
#                                         engine-internal and test/tool
#                                         buckets, not out of NOWHERE)
#     unconsumed        2251 -> 2251     <- the number the ratchet reads
#
# That last line is the point, and it is measured rather than argued: a symbol
# is appended to `unconsumed` BEFORE the user-project pass runs, and that pass
# only decides which sub-bucket displays it.
#
