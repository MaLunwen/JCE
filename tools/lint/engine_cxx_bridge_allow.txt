# First-party .cpp allowed under engine/src, one per line, with the
# third-party C++ library it bridges named after '#' on the SAME line.
# A bare path with no library is NOT an entry -- check_engine_cxx_bridges.py
# ignores it, so "I'll say which library later" fails closed.
#
# AGENTS.md §11: the engine is C99.  A .cpp exists here only because some
# third-party library has no C API and somebody has to speak C++ to it.  It is
# a THIN WRAPPER exposing a jce-style C surface, not a place to write C++.
#
# §11's own parenthetical named four libraries -- Bullet, ozz, Recast,
# behaviortree.cpp.  The tree actually bridges nine, listed below; the
# parenthetical was written when it was four and never revisited.  That is the
# reason this list exists in a file the gate reads instead of in prose.
#
# 2026-08-31: engine/src/middleware/video/jce_audio_stream.cpp was removed from
# this category rather than added to it.  381 lines, includes only jce headers
# and <string.h>, bridged nothing -- a C file with the wrong extension.  It
# compiled as C11 with zero errors and zero warnings unchanged, and is
# jce_audio_stream.c now.
#
# ---------------------------------------------------------------------------

Split from jce_physics_bullet.cpp at the 3000-line cap: it touches only bw->char_* plus world/ghosts/characters and calls no static defined there, so the seam is the same width as the vehicle one beside it
engine/src/middleware/physics/jce_physics_bullet_con_query.cpp # Bullet -- btTypedConstraint::getJointFeedback()/setJointFeedback() and btJointFeedback are C++-only; this TU owns one mechanism end to end (install the feedback storage at creation, read force and torque after each step) and exists because keeping those halves apart is how they drifted
engine/src/middleware/physics/jce_physics_bullet_contact.cpp # Bullet -- gContactAddedCallback is a C++ global whose signature takes btManifoldPoint& and btCollisionObjectWrapper*, so the hook cannot be C; this TU owns the one global contact hook end to end (install it at world create, chain to any previous owner, and run everything that influences a contact inside it) and exists because its installation used to live inside the heightfield path, which is the same drift the con_query file above records
