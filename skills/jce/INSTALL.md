# JCE skill installation

Source: this repository's skills/jce. Read it directly on cloud hosts.
For local discovery, link the runtime's jce skill entry to this directory.
Preserve an existing directory before replacing it with a link; do not overwrite
its contents. Windows uses a directory junction, Unix a symbolic link.
The repository file is the single source; edits immediately reach linked hosts.
Unpublished private skill extensions are not included in the public archive.
