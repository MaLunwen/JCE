# Maintained repository state

AGENTS.md owns engineering rules. contracts/module-memory-index.md maps module charters; contracts/source-layout.json owns publication boundaries. README.md and its generated facts describe the tracked source.

Use current indexed files and executed checks for counts. Historical notes, a public web snapshot or a stale build directory do not describe the current working tree automatically.

Public source must work without docs/, .docs/, private/, local fonts, external project assets or a globally installed skill. Preserve originals and local delivery records while excluding them from public commits.

The default skill is skills/jce/ in en-US. The corresponding Simplified Chinese edition is skills/jce-zh-cn/. Keep the reference inventory, commands and maintained responsibilities equivalent; change both editions together.
