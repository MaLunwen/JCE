# 代码与文本规范

自有引擎代码使用 C99，编辑器使用 C++20。C++ 依赖由批准的 C 桥封装。公开头需自包含；公开新头时更新所属 API 伞头。

使用 JCE 的分配、文件系统、线程和数学包装。平台细节放入 engine/src/os/platform/。通用引擎及编辑器不包含用户项目的专用业务。

自有文本在磁盘和 Git 中均使用 LF。BAT/CMD 在磁盘使用 CRLF，在 Git 中使用 LF。保留二进制资产和第三方原件字节。.editorconfig 与 .gitattributes 是格式依据；不根据已有混合换行文件猜测格式。

文件体积检查执行软上限 2,000 行、硬上限 3,000 行。按职责拆分，不为增长随意抬高基线。修复行为时避免无关格式改动。
