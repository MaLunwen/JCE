# 编写消费项目

AI CLI 是开发期的应用消费端，只通过公开 API/SDK、文档、仓库 Skill、示例、
编辑器操作和受支持的构建工具开发应用。不通过查看或修改引擎、编辑器内部实现
绕过缺失的应用能力。报告通用 API/编辑器缺口及复现方法；若授权维护引擎，
需作为独立范围的任务验证。消费项目的场景、组件数值、平衡和驱动语言代码
留在该项目下。这一通用边界不公开专用创作策略。

生成场景数据前，先发现受支持的组件与字段。

```bash
python tools/jce_scene_kit.py schema
python tools/jce_scene_kit.py schema --type Camera
python tools/jce_scene_kit.py check <scene.json>
```

优先使用组件配置和已有脚本宿主操作，避免手写引擎业务。核对实际字段 schema、相机约定、项目设置和语言清单，不虚构属性。

正交相机需检查 API 的 ortho-size 含义，并在目标视口宽高比验证取景。比较图像前，使编辑器游戏视图与出货程序使用相同渲染后端。

优先使用配置的默认字体或系统字体回退。字体族名字不能证明字体已加载或拥有许可。导入模型、纹理、音频和字体随项目保留来源与条款；资源复用或创作遵循用户授权的工作流。

区分开发期 AI 辅助与游戏运行时 AI 行为。通用模型传输机制公开；未公开的 CLI、Agent、场景和物理策略及私有提示词不能进入公开源码或 skill 包。

改动后重复完整应用生命周期验证：检查受支持的场景字段和组件，编辑器模拟，
通过匹配 SDK 构建并运行对应平台可执行程序，打包 bundle 并重新在编辑器打开，
比较实际设置、输入、脚本行为、资产、画面和释放过程。迁移原生应用并排除松散
文件及源码树回退。记录各宿主、语言/后端、产物身份和实际结果。模型响应成功、
编译通过或打包目录存在不能替代验收。失败结果进入下一次公开 API 迭代；
缺失的宿主验证明确标为不可用。
