## 2. 十二个主线任务

### M01 — 醒来 / Wake

目标：移动、相机、拾取、物品栏和到达出口。  
场景：A 区小范围。  
资产：Kael、废墟、晶币、任务货箱、教学 UI。  
奖励：基础治疗和少量晶币。

### M02 — 第一场麻烦 / First Trouble

目标：徒手战斗、锁定、闪避、触发 Wanted 1 并脱离追捕。  
敌人：2 个街头守卫。  
奖励：木棍和商店解锁。

### M03 — 跑起来 / First Run

目标：进入魔法马车、通过检查点、撞开路障并抵达难民营。  
引入：载具、电台占位、载具损伤和驾驶检查点。

### M04 — 不情愿的英雄 / Reluctant Hero

目标：见 Sera、护送平民、防守两波敌人并完成态度对话。  
结果：抵抗军任务线开启。

### M05 — 过境货物 / Border Cargo

目标：获取货物、驾车通过 A→B、避开或击破检查点、Wanted 2 逃脱并交货。  
结果：解锁拉斯帕兹。

### M06 — 老鼠的规矩 / Rat's Rules

目标：见 Rat、找到债务人、选择威胁或战斗、带回晶币。  
结果：黑市、Wanted 清除和动态委托初级模板。

### M07 — 自由电波 / Free Airwaves

目标：见 Lily、前往电台中继站、击败守卫、恢复广播并在载具中听到首次动态新闻。  
结果：三个电台频道和 Lily 支线。

### M08 — 地下之王 / Arena King

目标：进入竞技场、完成三波战斗并击败重装骑士。  
结果：竞技场活动、短剑和声望阈值。

### M09 — 晶库大劫案 / Crystal Vault

阶段：

1. 侦察入口；
2. 获取进入工具；
3. 潜入或强攻；
4. 取得晶币；
5. 符文车逃脱；
6. Wanted 4 逃离。

结果：大额资金、符文车、符文枪和安全屋购买条件。

### M10 — 一块屋顶 / A Roof of Your Own

目标：购买安全屋、安装基础服务、抵御敌人报复并完成首次手动保存。  
结果：B 区安全屋、第二载具出生和装备管理。

### M11 — 西区燃烧 / West Burns

阶段：

1. 破坏三个熔炉节点；
2. 护送冷却符文；
3. 进入 Boss 场；
4. 击败薇雯；
5. 逃出熔炉。

结果：西区解放、特殊升级、城市视觉变化和 Wanted 5。

### M12 — 最后一场演出 / Final Performance

阶段：

1. 潜入剧院；
2. 识别假演员；
3. 后台追逐；
4. 米拉 Boss；
5. 结局选择。

选择：

- 支持 Sera，建立抵抗军政府；
- 支持 Rat/市民，让拉斯帕兹独立。

完成后进入自由探索，电台播放后日谈，动态活动继续。

## 4. 四类重复活动

### 限时送货

变量：起点、终点、时间、货物耐久、交通和 Wanted。

### 通缉目标

变量：敌人原型、区域、护卫、目标状态和奖励。

### 街头竞速

- 3 条正式路线；
- 魔法马车与符文车分组；
- 铜/银/金时间；
- 仅本地排行。

### 竞技场

- 3 种波次模板；
- 难度随主线解锁；
- Boss Rush 不进入首发。

## 5. 世界状态变化

### 初始

- A 区低级守卫；
- B 区高敌对；
- 西区熔炉污染；
- 剧院区幻影巡逻；
- 商店库存有限。

### 薇雯被击败后

- 西区火焰降低；
- 焰魔减少；
- 工人和平民返回；
- 新商店库存；
- 电台新闻更新。

### 米拉被击败后

- 剧院灯光恢复；
- 影刺客减少；
- 结局阵营旗帜；
- 城市 NPC 台词改变。

世界状态必须数据化保存，不能只由场景临时脚本控制。

## 6. 对话内容预算

### 主线

- 每任务 6–15 个短节点；
- 两个 Boss 前后各 15–25 个节点；
- 两个结局各 20–30 个节点。

### 支线

每个 4–8 个节点。

### 街头 Barks

- 平民：20；
- 守卫：20；
- 关键 NPC：每人 10–15；
- Boss：每位 12–20。

首发默认文本 + 少量短语音，不做完整角色配音。

## 7. 检查点规则

每个主线至少设置：

- 任务开始；
- 主要阶段完成；
- Boss 开始；
- 任务结束前。

检查点必须保存玩家、装备、任务阶段、关键敌人、目标物、载具、Boss 状态和任务临时世界状态。

## 8. 任务验证

每个任务必须验证：

- 首次正常路线；
- 死亡重试；
- 载具摧毁；
- 离开区域；
- 保存退出；
- 加载继续；
- 快速跳过对话；
- 低性能；
- 键鼠；
- 手柄；
- 不同难度；
- 目标被意外提前消灭；
- 重复触发；
- 世界流式卸载/加载。

任何导致主线无法继续的问题均为 P0。
